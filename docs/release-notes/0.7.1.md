## Fixes

- **Sync on Linux with Hyprland, sway and other window managers.** UniOS now uses your Secret Service keyring (gnome-keyring, KeePassXC) there instead of failing with "Secure storage is not available". Without any keyring, your sign-in and keys are kept in a file only your user account can read, and Settings tells you so. This also applies to saving API keys.
- **Easier sync setup.** You can paste the Supabase dashboard link as the project URL; UniOS turns it into the right address. A wrong address now gets a clear message instead of "Unexpected token '<'". The setup text names the publishable key and warns never to paste the secret key.
- Files holding secrets are always written readable by your user account only.

## Install

Already on 0.6.x or 0.7.0? Use the update notice in the sidebar. Use the same version on all computers you sync. Otherwise download the file for your system below:

| System | File |
|---|---|
| macOS – Apple Silicon (M1–M4) | `UniOS-0.7.1-arm64.dmg` |
| macOS – Intel | `UniOS-0.7.1-x64.dmg` |
| Windows 10/11 | `UniOS-Setup-0.7.1-x64.exe` |
| Linux | `UniOS-0.7.1-x86_64.AppImage` or `UniOS-0.7.1-amd64.deb` |
