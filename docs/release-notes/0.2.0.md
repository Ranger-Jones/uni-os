## What's new

- **Updates inside the app.** UniOS now checks for new versions and shows them in the sidebar together with these release notes. On macOS, Windows and Linux (AppImage) one click downloads and installs the update; after restarting you'll see what changed. You can turn automatic checks off in *Settings → Updates*.
- **Links between pages.** Type `[[` or `@` in a note to link to another page. Links always show the page's current title, open it with a click, and every page lists the pages that link to it under *Linked from*. If the page doesn't exist yet, you can create it right from the menu.
- **Tags for course files.** Mark files as *Lecture*, *Exercise*, *Solution*, *Notes*, *Exam*, *Literature* or your own tags, and filter the file list by tag. New files get a suggested tag from their name (e.g. "Übungsblatt 3.pdf" → Exercise).
- **Smarter assistant.** The assistant (and Claude Desktop via MCP) understands page links and file tags — ask it to "link the matching lecture notes" or to "show all exercise sheets".

## Fixes

- Editor images are now stored with their page and removed when the page or course is deleted.
- Stricter checks on file paths used for editor attachments.

## Install

| System | File |
|---|---|
| macOS – Apple Silicon (M1–M4) | `UniOS-0.2.0-arm64.dmg` |
| macOS – Intel | `UniOS-0.2.0-x64.dmg` |
| Windows 10/11 | `UniOS-Setup-0.2.0-x64.exe` |
| Linux | `UniOS-0.2.0-x86_64.AppImage` or `UniOS-0.2.0-amd64.deb` |

Coming from 0.1.0? Install this version once by hand — from now on updates arrive inside the app.

The builds aren't signed with a paid Apple/Microsoft certificate, so the first launch needs one extra click: on macOS open the app once, then *System Settings → Privacy & Security → Open Anyway*; on Windows choose *More info → Run anyway*.
