## What's new

- **Sync between your computers.** Keep UniOS in sync on two (or more) computers through your own free Supabase project. Set it up once in **Settings → Sync between devices**: create a Supabase project, paste its URL and anon key, run the setup SQL shown in the app, sign in and choose a sync password. After that it runs by itself — at start, a few seconds after every change and every few minutes — and the sidebar shows when it last synced.
- **End-to-end encrypted.** Everything is encrypted on your device with your sync password before it is uploaded; your Supabase project only stores ciphertext. Tampered or replayed data from the cloud is detected and ignored.
- **Nothing gets lost.** If you edit the same note on both computers before they sync, the edits are merged block by block. UniOS keeps working offline and catches up later.
- **What syncs:** courses, notes (including images), assignments, calendar, grades, flashcards with your learning progress, quizzes and exams with your results, chats, links and files up to 50 MB. Videos and bigger files stay on the computer they were added on. Settings and API keys are per device.

## Improvements

- Number questions in quizzes and exams accept fractions such as `3/20`.

## Install

Already on 0.6.x? Use the update notice in the sidebar. Use the same version on all computers you sync. Otherwise download the file for your system below:

| System | File |
|---|---|
| macOS – Apple Silicon (M1–M4) | `UniOS-0.7.0-arm64.dmg` |
| macOS – Intel | `UniOS-0.7.0-x64.dmg` |
| Windows 10/11 | `UniOS-Setup-0.7.0-x64.exe` |
| Linux | `UniOS-0.7.0-x86_64.AppImage` or `UniOS-0.7.0-amd64.deb` |
