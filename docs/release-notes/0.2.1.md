## What's new

- **Links and videos as course materials.** The *Files* tab is now called *Materials*. Add any web resource with **Add link** — course website, paper, tool or lecture recording — give it a name, tags and a note. Video links (YouTube, Vimeo, Opencast, Panopto, …) are recognised automatically.
- **Video files play inside UniOS.** Drop lecture recordings (mp4, mov, webm) into a course and watch them in the preview, including seeking. Large recordings (up to 8 GB) are copied without slowing the app down.
- **Filter by type.** Next to the tag filters you can now show only *Files*, *Links* or *Videos*.
- **Search and assistant.** Links are found with ⌘K / Ctrl+K, and the assistant (and Claude Desktop via MCP) can list and add links for you.

## Security

- Updates are now signed. UniOS only installs an update after verifying the release signature, the download source, and that the downloaded app is the announced, newer UniOS version.
