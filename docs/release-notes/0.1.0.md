First release of **UniOS** — your studies in one place: courses, notes, assignments, timetable, grades and flashcards, with an AI assistant (Claude or OpenAI).

## Features

- Semesters and courses with ECTS, colours and a weekly timetable
- Notion-style block editor for notes, with LaTeX formulas (`/Formula`)
- Assignments, exams, week/month calendar and a Today overview
- Grades (German scale 1.0–5.0) with ECTS-weighted average and "what do I need" forecast
- PDFs via drag & drop, full-text searchable
- Flashcards with spaced repetition, optionally written by the assistant
- Search everything with ⌘K / Ctrl+K
- Assistant with ⌘J / Ctrl+J (bring your own Anthropic or OpenAI API key)
- Connect Claude Desktop / Claude Code via MCP (*Settings → Connect Claude*)

All data stays on your computer (by default in a `UniOS` folder in your home directory).
