## What's new

- **Swipe back and forward.** Swipe with two fingers on the trackpad to go back to the previous page (to the right) or forward again (to the left), like in a browser. An arrow at the edge shows it while you swipe. This works after following a link to another page, and from exam results: open a question's source page, swipe back, and you are on the same results again. The mouse's back/forward buttons and ⌘[ / ⌘] (Alt+← / Alt+→ on Windows and Linux) work too.
- **No lost answers.** Leaving a test you are taking (by swiping, the sidebar, …) now asks first once you have answered something.

## Install

Already on 0.6.x or later? Use the update notice in the sidebar. Use the same version on all computers you sync. Otherwise download the file for your system below:

| System | File |
|---|---|
| macOS – Apple Silicon (M1–M4) | `UniOS-0.7.2-arm64.dmg` |
| macOS – Intel | `UniOS-0.7.2-x64.dmg` |
| Windows 10/11 | `UniOS-Setup-0.7.2-x64.exe` |
| Linux | `UniOS-0.7.2-x86_64.AppImage` or `UniOS-0.7.2-amd64.deb` |
